# Jennie Santana Makeup | Minisite

Minisite da maquiadora **Jennie Santana Makeup**. Página estática em HTML e CSS, sem dependências nem build.

- Instagram: https://www.instagram.com/jenniesantanamakeup/
- WhatsApp: (81) 99690-1531

## Estrutura

```
index.html
css/style.css
assets/img/   logo (ícone da aba) e flyer
```

## Como ver no computador

Abra o `index.html` no navegador.

## Publicar no GitHub Pages

1. Envie os arquivos para um repositório (o `index.html` precisa ficar na raiz).
2. Vá em **Settings > Pages**.
3. Em **Source**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`.
4. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Publicar na Vercel

1. Em **Add New > Project**, importe o repositório do GitHub.
2. Framework Preset: **Other**. Deixe Build Command e Output Directory vazios.
3. Clique em **Deploy**.

## Como editar

- Links e telefone: `index.html`
- Posição das áreas clicáveis: `css/style.css` (`.ig`, `.wa`, `.ag`)
- Imagem: substitua `assets/img/flyer.jpg` mantendo o mesmo nome e as mesmas proporções
